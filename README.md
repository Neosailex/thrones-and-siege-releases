# Thrones & Siege — descargas

Juego de cartas y castillos para 2 jugadores (contra la CPU, con amigos u online).

**Descargar:** entrá a [Releases](../../releases/latest) y bajá `Thrones-and-Siege-Setup-x.y.z.exe` (Windows), `...-Mac-arm64.dmg` / `...-Mac-x64.dmg` (Mac Apple Silicon / Intel) o `...-Linux.AppImage` (Linux).
En Mac, la primera vez: clic derecho > Abrir ([instrucciones](INSTALAR-MAC.md)).
Una vez instalado, el juego se actualiza solo cada vez que lo abrís.
