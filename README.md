# Thrones & Siege — descargas

Juego de cartas y castillos para 2 jugadores (contra la CPU, con amigos u online).

**Descargar:** entrá a [Releases](../../releases/latest) y bajá `Thrones-and-Siege-Setup-x.y.z.exe` (Windows).
Una vez instalado, el juego se actualiza solo cada vez que lo abrís.
